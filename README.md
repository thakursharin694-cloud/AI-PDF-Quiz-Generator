 # AI-Powered PDF Quiz Generator

## 📌 Overview

AI-Powered PDF Quiz Generator is an interactive application that automatically generates multiple-choice quizzes from PDF documents using Artificial Intelligence.

Instead of manually creating questions from study material, users can upload a PDF and generate a quiz based on its content.

## ✨ Features

- 📄 Upload PDF documents
- 🤖 Generate MCQ questions using AI
- 🔢 Choose the number of questions
- 📊 Select quiz difficulty
- ⏱️ Optional time limit for questions
- 📝 Interactive quiz interface
- ✅ Automatic answer evaluation
- 📈 Score and percentage calculation
- 🔍 Review correct and incorrect answers
- 🔄 Retry the same quiz
- 📚 Generate a new quiz from another PDF

## ⚙️ How It Works

1. Upload a PDF document.
2. Select the number of questions.
3. Select the difficulty level.
4. Choose the time limit.
5. Click **Generate Quiz**.
6. Answer the generated MCQs.
7. Submit the quiz to view your score.
8. Review your answers and correct answers.

## 🛠️ Technologies Used

- Python
- Streamlit
- Mistral AI
- PyPDF2
- LangChain
